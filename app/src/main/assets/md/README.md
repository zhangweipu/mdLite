# mdLite · Markdown 阅读器

一个基于 **Jetpack Compose + MVI** 的 Android Markdown 阅读示例项目。

## 功能特性

- 自动扫描内置 Markdown 文档列表
- 渲染常见 Markdown 语法：标题、段落、**粗体**、*斜体*、`行内代码`、列表、引用、代码块、链接
- 界面尺寸自动适配手机 / 平板 / 大屏

> 提示：文档放在 `app/src/main/assets/md/` 目录下，应用启动后自动扫描。
